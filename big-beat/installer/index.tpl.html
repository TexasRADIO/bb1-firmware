Install Big Beat Studio BB1

Install BB1 and its matching sound library on a compatible FM-1.

Install BB1 · Remove BB1 / switch firmware · Installation help

Before writing firmware: verify that this FM-1 enters ROM mode (USB 4C4A:8057) using a route that works independently of the installed application. Confirm the recovery tool can communicate with that endpoint and that the route survives the write. Make two matching full-flash backups from independent reads and verify a compatible restore path. After updating, check ROM access again and confirm a normal boot. ROM recovery checklist.

Connect one FM-1 after the ROM checks, then confirm the checks below.

  • desktop Chrome on a computer
  • A USB data cable, plugged straight into the computer
  • Playback stopped, MASTER turned fully down
  • Other music apps closed

Use the starting firmware versions listed above. If your version is missing from the list, check the return instructions for your current firmware. If you are running another community firmware, follow its documented return procedure first. New BB1 builds first identify with the short M-UPGRADE-compatible family ID FM-1_922; this installer then asks for and checks the complete numeric runtime ID before writing.

Chrome is the release browser target. Brave has a MIDI/SysEx site-permission setting, but has not been qualified for this installer. Other browsers are not release-qualified. Browser checks and loader help.

Don't unplug or power off while writing. An interrupted MIDI updater and ROM recovery are different states. Read the troubleshooting steps below before retrying.

1 Install

Installs BB1 2.1 and its matching sound library 2.1, including the sampled machines and on-device help. The USER kit builder is included. SLOOP kits have been removed; older projects that depend on them are unsupported. Keep a backup of your music before changing firmware; other firmware may replace data that BB1 needs. Read what to save and which flash regions overlap first.

Remove BB1 / return to official firmware

Keep a backup made with the firmware you plan to return to. Older BB1 releases may refuse scenes created with newer features; the official firmware cannot open BB1 projects.

BB1 2.1.1 and M-UPGRADE 3.11: the public 2.1.1 build can make M-UPGRADE say the FM-1 did not answer because that updater rejects its long identity. This build answers M-UPGRADE's plain discovery query as FM-1_922 while retaining the complete numeric identity for BB1's own installer. The return control below checks the official firmware file before writing.

Switching to another community firmware? Unless its own instructions explicitly say it accepts Big Beat, return to unchanged official firmware here first. Then close this page and follow the new firmware's own instructions. Do not choose another firmware's file on this page.

Download the current official FM-1 firmware from M-VAVE and choose the unchanged FM-1.fwsc here. Current V16 and the previously verified V15 are accepted by exact digest. The file is checked in this browser and never uploaded.

Choosing the file only checks it. Nothing is written until you press Return to official firmware and confirm.

The official firmware can't open BB1 music. Use the project-file export to keep the current project where available, and keep separate copies of every scene and USER kit you need. A project file is not a full device or sample-bank backup. See the backup checklist.

Connect MIDI before confirming the ROM checks.

Installation help

FM-1 not found. Try another USB cable (some only charge), plug straight into the computer, and close other apps that use MIDI.

Loader not appearing. Allow MIDI access including SysEx in this site's browser permissions, close every other MIDI app or installer tab, and use a direct USB data cable. Wait for this attempt to finish or show an error before reconnecting. If the MIDI update loader is then visible, retry this same package. WL80UBOOT / ROM mode is not the MIDI loader; stop browser retries in that state and use a separately verified recovery procedure. Full steps and browser status.

Firmware updated, sounds could not be verified. The firmware and sound library are separate steps. Keep the FM-1 connected and save the installation log below. If the flash chip could not be verified, stop and identify the chip before trying another sound-library write.

The browser asked about MIDI devices. Allow it: that's how this page talks to the FM-1. Nothing is sent anywhere else.

The FM-1 won't start at all. See FM-1 Transporter for a hardware-assisted recovery route. A blank screen or ROM USB mode may need additional hardware; browser retry is not a proven recovery route for that state.
