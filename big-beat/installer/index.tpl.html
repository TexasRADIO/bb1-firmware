This browser can't talk to the FM-1. Open this page in desktop Chrome on a computer.

Start from corrected-ID BB1 1.5 (FM-1_92200105). This 2.1 installer also accepts BB1 2.0 (FM-1_92200200) and BB1 2.1 (FM-1_92200201). Stock V15, older BB1 and other firmware must first use the retained BB1 1.5 installer. The runtime ID is checked before the update starts.

Chrome is the release browser target. Brave has a MIDI/SysEx site-permission setting, but has not been qualified for this installer. Other browsers are not release-qualified. Browser checks and loader help.

Don't unplug or power off while writing. An interrupted MIDI updater and ROM recovery are different states. Read the troubleshooting steps below before retrying.

Remove BB1 / return to official V15

Keep a backup made with the firmware you plan to return to. Older BB1 releases may refuse scenes created with newer features; the official firmware cannot open BB1 projects.

Download the official FM-1 V15 from M-VAVE and choose the unchanged FM-1.fwsc here. It's checked in this browser and never uploaded.

Choosing the file only checks it. Nothing is written until you press Return to official V15 and confirm.

The official firmware can't open BB1 music. Use the project-file export to keep the current project where available, and keep separate copies of every scene and USER kit you need. A project file is not a full device or sample-bank backup. See the backup checklist.

Installation help

FM-1 not found. Try another USB cable (some only charge), plug straight into the computer, and close other apps that use MIDI.

Loader not appearing. Allow MIDI access including SysEx in this site's browser permissions, close every other MIDI app or installer tab, and use a direct USB data cable. Wait for this attempt to finish or show an error before reconnecting. If the MIDI update loader is then visible, retry this same package. WL80UBOOT / ROM mode is not the MIDI loader; stop browser retries in that state and use a separately verified recovery procedure. Full steps and browser status.

The browser asked about MIDI devices. Allow it: that's how this page talks to the FM-1. Nothing is sent anywhere else.

The FM-1 won't start at all. See FM-1 Transporter for a hardware-assisted recovery route. A blank screen or ROM USB mode may need additional hardware; browser retry is not a proven recovery route for that state.
