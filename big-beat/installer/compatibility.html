Loader not appearing

  1. Open this installer over HTTPS in desktop Chrome. Allow MIDI access, including control/reprogramming (SysEx), for this site. Reload after correcting a denied permission.
  2. Close other music apps and other installer tabs. Connect one FM-1 directly with a USB data cable. Keep playback stopped and MASTER fully down.
  3. Check the accepted starting firmware IDs on the installer page for the package you are using. A newer BB1 first answers with the M-UPGRADE-compatible family ID FM-1_922; the installer then requests and validates its complete numeric identity. If you are on another firmware, check its documented return procedure before installing BB1.
  4. Wait until the current attempt reports completion or an error. Do not unplug or power off during an active write. If no MIDI loader appears, check the permissions and cable before starting a new attempt.
  5. An interrupted MIDI loader can be resumed only with the same installer and package. Do not change firmware installers during recovery. WL80UBOOT1.00 / USB 4c4a:8057 is the chip ROM, which this installer cannot use. A blank screen alone does not identify the state. Stop retries and seek a verified recovery procedure if ROM mode is confirmed.

Switching from BB1 to another firmware

BB1 2.1.1 and M-UPGRADE 3.11: the public 2.1.1 build may make M-UPGRADE report that the FM-1 did not answer because it rejects the long identity. New BB1 builds answer the plain discovery query as FM-1_922 and keep the complete numeric identity for BB1's own installer. An updater-discovery problem is not evidence of a bricked FM-1. The BB1 return control remains the verified route.

Unless the new firmware's own instructions explicitly say it accepts Big Beat, use the BB1 installer's Remove BB1 / switch firmware section to return to unchanged official firmware first. The control accepts only exact current V16 or verified legacy V15 packages. After the selected stock firmware starts normally, close the BB1 installer and follow the new firmware's own instructions. Never choose another community firmware's package in the BB1 return control, and never change installers while an update or recovery is in progress.

Brave permission reference

Brave documents MIDI device control & reprogram under Settings → Privacy and security → Site & Shield Settings, with site-specific overrides. That capability is not evidence that the 2.1 update/return flow has passed in Brave.
