Browser support and loader help

Release installer target: desktop Google Chrome, with permission to control and reprogram MIDI devices (SysEx). The installer uses USB-MIDI, not WebUSB.

Loader not appearing

  1. Open this installer over HTTPS in desktop Chrome. Allow MIDI access, including control/reprogramming (SysEx), for this site. Reload after correcting a denied permission.
  2. Close other music apps and other installer tabs. Connect one FM-1 directly with a USB data cable. Keep playback stopped and MASTER fully down.
  3. The installer checks the running firmware identity. Start from corrected-ID BB1 1.5 (FM-1_92200105), BB1 2.0 (FM-1_92200200), or BB1 2.1 (FM-1_92200201) for a reinstall. For stock or an older version use the 1.5 bridge first.
  4. Wait until the current attempt reports completion or an error. Do not unplug or power off during an active write. If no MIDI loader appears, check the permissions and cable before starting a new attempt.
  5. An interrupted MIDI loader can be resumed with the same package. WL80UBOOT1.00 / USB 4c4a:8057 is the chip ROM, which this installer cannot use. A blank screen alone does not identify the state. Stop retries and seek a verified recovery procedure if ROM mode is confirmed.

Brave permission reference

Brave documents MIDI device control & reprogram under Settings → Privacy and security → Site & Shield Settings, with site-specific overrides. That capability is not evidence that the 2.1 update/return flow has passed in Brave.
