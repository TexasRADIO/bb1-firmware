# Big Beat shared effects candidates

The original `bb_echo` candidate is a three-head, full-rate, float tape-style effect, not a circuit-accurate RE-201/RE-501 model. It uses high/low-pass coloration, a bounded soft recording curve, fractional reads, slewed time and periodic wow. Its 128 KiB tape holds about743ms at44.1kHz; the user-facing longest head is limited to700ms. Preserve this honest limit while developing a deliberate longer-delay storage policy.

r19 adds an **original Big Beat Motion** implementation: deterministic slow head-position and stereo-pan targets every20..60seconds of processed audio, eased with an eight-second time constant and a separately smoothed0..100depth control. Heads remain ordered within disjoint ranges; feedback amount is not randomized. Disabling Motion eases home without clearing tape. A fixed seed makes tests and a restarted session reproducible. This is inspired by the documented AMB idea, not copied AMB code, not all of AMB's Motion behavior and not pattern evolution. Zero Motion is verified against the frozen original r18b engine retained only as a test reference in `tests/reference/`. All paths are allocation-free; target timing and listening remain unmeasured.

`bb_spring.c` and `.h` are GPL-3.0-only adaptations of the spring in pinned Felucca revision `ef1f561b6b105f20350f6b1eac0dc0789a357f00`, `firmware/src/fx.c`, copyright (C) 2026 Leo Kuroshita (@kurogedelic), Hügelton Instruments. The unchanged licensed source and repository licence remain retained under the separate build-setup reference. The ten four-sample stretched allpasses, source gain staging and loop-feedback/damping range are retained. This new candidate uses float state, interpolated loop reads and caller-independent per-sample size slew; it omits the reference pickup wobble. It is **not fixed-point-equivalent**, a listened/tuned Big Beat release or an authenticated physical-tank simulation. Rate validation deliberately stops at 48 kHz so the 4096-frame line holds the specified 60 ms maximum.

Effects are shared, wet-only returns, separate from instrument patches and sequence state. Drum sends are post-voice, post-part-fader; stop/mute suppress new notes, not existing effect tails. No feedback connection exists from echo to spring or spring to echo. Host tests cannot establish FM-1 deadline cost, target memory fit, analogue sound quality or full-band acceptance. No redistribution or publication is authorized.
