# BB1

BB1 is an FM-1 groovebox with two independent drum layers, Dillo bass, effects, per-song effects recall, retrospective capture, Screen companion and Sideman USB transmission.

## BB1 2.3 shared-editor release

[Download v2.3-editor.1](https://github.com/TexasRADIO/bb1-firmware/releases/tag/v2.3-editor.1)

This release keeps firmware version **2.3** and adds the shared-editor working-state protocol: read the current working state, send edits and control play/stop. Editor state files are distinct from full device projects; native project transfer and automatic device-originated parameter updates are outside this package's documented editor surface.

The release includes FM-1 firmware, its matching sound library, complete corresponding source, Firmware Hub card and image, licence notices and download checksums.
